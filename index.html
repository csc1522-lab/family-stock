백업 내보내기 / 가져오기

실시간 시세 조회는 다운로드한 파일에서만 작동하고, PC·폰 간 자동 동기화는 지원되지 않습니다. 대신 이 기능으로 데이터를 파일로 저장해서 카카오톡 "나에게 보내기" 등으로 다른 기기에 옮기실 수 있습니다.
⚠️ 가져오기를 하면 현재 이 기기에 있는 데이터는 덮어써집니다.

실시간 시세 API 설정

KIS API용 Cloudflare Worker 프록시 주소를 입력하세요. 리와인드_자산관리 앱에서 쓰신 Worker를 그대로 재사용할 수 있습니다. 정확한 요청/응답 형식을 모르면 "연결 테스트"로 원본 응답을 확인하고 JSON 경로를 맞추면 됩니다.
{base}=위 주소, {code}=종목코드 로 치환됩니다. 예: {base}/price?code={code}
KIS API 기본 필드명입니다. 응답 구조가 다르면 테스트 결과를 보고 수정하세요. (예: data.price, output.stck_prpr)
